# OneStrike

FPS para Windows com quatro armas, inimigos controlados pelo jogo e três setores de captura.

## Jogar no Windows

Baixe o ZIP em [Releases](https://github.com/PedroCaitano28/OneStrike/releases/latest), extraia e abra **OneStrike.exe**. O Godot está incluído no executável.

WASD move, Shift corre, Ctrl ou C agacha, Espaço pula, botão direito mira, 1–4 troca de arma, R recarrega e T alterna o silenciador. F10 abre as configurações.

## Editar

Importe `project.godot` no Godot 4.7.2. Para exportar, use o preset **Windows Desktop** com os templates oficiais da mesma versão.
